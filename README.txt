Upload everything in this folder (keep the folders as they are) to any static web host, at the root
of a site or in a sub-folder, for example https://slideread.yourdomain.com/ or https://yourdomain.com/slide/.
No server code or database is needed. The site must be served over https (needed for offline use).

Files
- index.html             the app
- sw.js                  lets the app open with no internet once it has been opened once
- manifest.webmanifest   name and icons for "Add to Home Screen"
- icons/                 app icons
- fonts/                 Andika (SIL Open Font License, see fonts/OFL.txt)
- LICENSE                the licence (PolyForm Noncommercial 1.0.0)
- CNAME                  the web address for GitHub Pages: blendaroo.zanarmstrong.com (keep it when uploading a new version)

Add to the home screen
- iPhone / iPad (Safari): Share button > Add to Home Screen.
- Android (Chrome): menu > Add to Home screen (or Install app).
Opening it from the home screen icon keeps its saved progress safe from Safari's 7-day clean-up of website data.

Saved progress
- Everything is saved on the device. Nothing is sent to any server.
- Settings > "Send to another device" makes a link with this device's words and aliens.
  Open it on the other device to add them there. Send it to yourself as a backup, too.

Updating
- Upload the new files over the old ones. The app picks up the new version the next time it is opened with internet.
